# Launch kit for Michelle

Ready-to-use announcements for the new site, written in the same voice as the site. Copy, paste, and post. Change anything that doesn't sound like you.

The site: **www.thelawtoncollection.com**

## 1. The links to share

Each link has a small tag on the end. The tag is invisible to the person clicking, but it tells the site which post the lead came from, so you'll know what's working.

| Where you're posting | Link to use |
|---|---|
| Facebook, your page | `https://www.thelawtoncollection.com/?utm_source=facebook&utm_medium=social&utm_campaign=launch` |
| Facebook, a town group | `https://www.thelawtoncollection.com/south-shore?utm_source=facebook&utm_medium=group&utm_campaign=launch` |
| Instagram bio | `https://www.thelawtoncollection.com/?utm_source=instagram&utm_medium=social&utm_campaign=launch` |
| Email to past clients | `https://www.thelawtoncollection.com/?utm_source=email&utm_medium=email&utm_campaign=launch` |
| Text messages | `https://www.thelawtoncollection.com/?utm_source=sms&utm_medium=text&utm_campaign=launch` |
| Printed flyers, open-house sheets | `https://www.thelawtoncollection.com/?utm_source=print&utm_medium=flyer&utm_campaign=launch` |
| Your email signature | `https://www.thelawtoncollection.com/?utm_source=signature&utm_medium=email` |

For a post about a specific place, link the matching page so the preview card shows it. For example, for an Easton listing:
`https://www.thelawtoncollection.com/south-shore/easton?utm_source=facebook&utm_medium=social&utm_campaign=easton-open-house`

Every page has its own preview card (navy, gold LC, the page name), so the post looks finished without adding a photo.

## 8. Put the link everywhere your name already is

Do these once. Each one sends people to the site for years.

- **Google Business Profile** (business.google.com): claim your profile, add the website, phone, and service area. This matters most for "real estate agent near me" searches.
- **CENTURY 21 agent profile**: add the website link.
- **Zillow, realtor.com, Homes.com agent profiles**: add the website link.
- **Facebook page**: About → Website. **Instagram**: bio link.
- **LinkedIn**: Contact info → Website.
- **Yard signs and business cards** on the next print run: www.thelawtoncollection.com

## 9. Small habits that pay off

- When you post, link the page that matches the post (a town page for a town post, Waterfront and fine homes for a waterfront listing).
- Tell people about **Save Michelle's contact** on the Contact page. One tap puts you in their phone.
- Print **How buying and selling works** (there's a Print button on the page) and bring copies to open houses.
- Ask happy clients for a Google review. Reviews on Google do more for you than reviews anywhere else.
